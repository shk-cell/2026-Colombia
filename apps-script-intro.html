Gemini 프롬프트
Google Apps Script 웹앱으로 돌림판을 만들어 줘. 스프레드시트 연동은 없고, 파일은 2개야.
1) Code.gs : doGet()에서 index.html 열기, 제목 '돌림판', 모바일 viewport 설정
2) index.html : canvas 돌림판, '돌리기' 버튼, 결과 표시, 항목 입력창(한 줄에 하나, 최대 12개)
파일별로 코드블록을 나눠서, 설명 없이 코드만 줘.
프롬프트를 복사해서 Gemini에게 물어보기

Gemini에게 물어보기

Gemini 프롬프트
Google 스프레드시트에서 연 Apps Script로 '우리 반 게시판' 웹앱을 만들어 줘. 파일은 2개야.

[Code.gs]
- 맨 위에 선생님 비밀번호 상수(TEACHER_PASSWORD) 두기
- '게시판' 시트에 글 저장 (없으면 제목 줄과 함께 자동 생성)
  열 : 번호, 작성일시, 이름, 제목, 내용, 댓글
- 글쓰기는 누구나 (빈칸·글자 수 검사, 동시에 써도 겹치지 않게)
- 글 목록(최신순) · 댓글 · 삭제는 선생님만, 비밀번호는 서버에서 확인

[index.html]
- 탭 2개 : 글쓰기 / 선생님 전용
- 글쓰기 : 이름·제목·내용 입력 + '글 남기기' 버튼, 결과 메시지
- 선생님 전용 : 비밀번호로 입장 → 글 목록, 댓글 등록, 삭제(확인창)
- 글 내용은 textContent로 표시, 모바일에서도 잘 보이게
파일별로 코드블록을 나눠서, 설명 없이 코드만 줘.
프롬프트를 복사해서 Gemini에게 물어보기
→
나온 코드 2개는 다음 장에서 붙여넣기Code.gs → index.html 순서

Code.gs 만들기

  1. Gemini가 준 Code.gs 코드를 복사해서, 안을 지우고 붙여 넣기
  2. 맨 위 비밀번호를 내 것으로 바꾸기
  3. 저장하기 (Ctrl + S)

index.html 만들기

  1. 왼쪽 파일 옆 + 버튼 → HTML
  2. 이름을 index로 정하기
  3. Gemini가 준 index.html 코드를 복사해서, 안을 지우고 붙여 넣기

이름은 꼭 index.html로 해야 합니다. Code.gs가 이 이름으로 화면을 찾아요.

배포하기

  1. 배포 → 새 배포 → 웹 앱 (설정은 실습 1과 동일)
  2. 스프레드시트 접근 권한 승인
  3. 주소(URL)를 학생에게 공유

코드를 고친 뒤에는 새 버전으로 다시 배포합니다.
